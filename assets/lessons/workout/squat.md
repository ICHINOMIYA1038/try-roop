# 正しいスクワットのフォーム

スクワットは「キング・オブ・エクササイズ」と呼ばれる最も効果的な運動の一つです。

## なぜスクワットが重要か

- 下半身の大きな筋肉を一度に鍛えられる
- 代謝アップに効果的
- 日常動作（座る・立つ）の改善

## 正しいフォーム

### スタートポジション

```
足幅: 肩幅か、やや広め
つま先: 少し外側に向ける（15〜30度）
腕: 前に伸ばすか、胸の前で組む
```

### 下降動作

1. **お尻を後ろに引く** - 椅子に座るイメージ
2. **膝はつま先と同じ方向** - 内側に入れない
3. **背中はまっすぐ** - 丸めない、反りすぎない
4. **目線は正面** - 下を向かない

### 下げる深さ

| 深さ | 説明 |
|------|------|
| クォーター | 膝45度まで |
| ハーフ | 太ももが斜め |
| パラレル | 太ももが床と平行 |
| フル | それ以上深く |

**初心者はパラレルを目指しましょう**

## よくある間違い

### 膝が内側に入る
- 足の外側を意識する
- つま先と膝を同じ方向に

### 背中が丸まる
- 胸を張る
- 目線を正面に
- 腹筋に力を入れる

### かかとが浮く
- 足裏全体で踏ん張る
- 体重を後ろに乗せる意識

## 段階的な練習法

### ステップ1: ボックススクワット
椅子やボックスに軽くお尻をつける

### ステップ2: 通常のスクワット
フリーで行う

### ステップ3: 負荷を増やす
- ゆっくり行う（3秒で下げて3秒で上げる）
- 回数を増やす

## 練習メニュー

```
初級: 10回×3セット
中級: 15回×3セット
上級: 20回×4セット
```

> 正しいフォームが最優先です。回数より質を意識しましょう。
