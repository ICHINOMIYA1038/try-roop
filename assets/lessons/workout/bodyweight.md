# 自重トレーニング入門

器具を使わず、自分の体重だけで行うトレーニング方法を学びましょう。

## 自重トレーニングのメリット

- **どこでもできる** - ジムに行かなくてもOK
- **コストゼロ** - 器具を買う必要なし
- **怪我のリスクが低い** - 自分の体重なので無理がない
- **機能的な筋力がつく** - 日常動作に直結

## 基本種目

### 1. プッシュアップ（腕立て伏せ）

**鍛えられる部位**: 胸、肩、腕

```
スタートポジション:
- 手は肩幅より少し広く
- 体は一直線に
- つま先で支える
```

**初心者向け**: 膝をついて行う

### 2. スクワット

**鍛えられる部位**: 太もも、お尻

1. 足を肩幅に開く
2. 背筋を伸ばす
3. お尻を後ろに引きながら下げる
4. 太ももが床と平行になるまで

### 3. プランク

**鍛えられる部位**: 体幹全体

| 時間 | レベル |
|------|--------|
| 20秒 | 初心者 |
| 45秒 | 中級者 |
| 60秒以上 | 上級者 |

## 初心者向けメニュー

週3回を目安に行いましょう。

```
1. プッシュアップ: 10回×3セット
2. スクワット: 15回×3セット
3. プランク: 20秒×3セット
4. 休憩: 各セット間30秒
```

## 継続のコツ

> 「毎日完璧にやる」より「週3回続ける」方が大事です。

- 同じ時間に行う習慣をつける
- 小さく始める
- 記録をつける
