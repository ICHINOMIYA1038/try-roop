# ストレス管理の基本

ストレスは避けられないものですが、上手に付き合う方法を学びましょう。

## ストレスを理解する

### ストレスとは

ストレスは「外部からの刺激に対する心身の反応」です。

適度なストレス（ユーストレス）は：
- 集中力を高める
- やる気を引き出す
- 成長を促す

過度なストレス（ディストレス）は：
- 心身の不調を招く
- パフォーマンスを下げる
- 病気のリスクを高める

### ストレスのサイン

| 身体面 | 心理面 | 行動面 |
|--------|--------|--------|
| 頭痛 | イライラ | 食べ過ぎ |
| 肩こり | 不安 | 睡眠の乱れ |
| 胃痛 | 集中できない | 引きこもり |
| 疲労感 | 気分の落ち込み | 趣味への興味低下 |

## すぐにできるストレス解消法

### 1. 呼吸法

**4-7-8呼吸法**

```
1. 4秒かけて鼻から吸う
2. 7秒間息を止める
3. 8秒かけて口からゆっくり吐く
4. これを3〜4回繰り返す
```

### 2. 体を動かす

- ウォーキング（10分でもOK）
- ストレッチ
- 階段を使う

> 運動すると「幸せホルモン」と呼ばれるエンドルフィンが分泌されます。

### 3. マインドフルネス

「今この瞬間」に意識を向ける練習：

1. 静かな場所に座る
2. 目を閉じる
3. 呼吸に意識を向ける
4. 雑念が浮かんでも、そっと呼吸に戻す
5. 5分から始める

## 日常でできる予防法

### ライフスタイルの見直し

```
□ 十分な睡眠（7〜8時間）
□ バランスの良い食事
□ 定期的な運動
□ 趣味の時間
□ 人との交流
```

### 考え方のコツ

**認知の歪みに気づく**

- 「〜すべき」思考を手放す
- 完璧を求めすぎない
- 他人と比較しない

**リフレーミング**

ネガティブな出来事を別の視点で見る練習：

```
「失敗した」→「学びを得た」
「できない」→「まだできないだけ」
「最悪」→「これで最悪ということは、これ以上悪くならない」
```

## ストレス日記をつける

毎日記録することで、パターンが見えてきます：

1. 日時
2. ストレスを感じた状況
3. その時の気持ち（10段階で）
4. 対処したこと
5. 結果

## まとめ

ストレス管理の基本：

1. **気づく** - ストレスのサインを見逃さない
2. **解消する** - 自分に合った方法を持つ
3. **予防する** - 生活習慣を整える
