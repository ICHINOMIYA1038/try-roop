# 昇級審査でみられるところ

審査は「新しい技ができるか」ではなく、「これまでの技が身についているか」を見る場です。落ちる人の多くは、新しく覚えた型ではなく、基本で崩れています。

## 審査の一般的な構成

| 項目 | 内容 |
| --- | --- |
| 基本 | その場基本、移動基本 |
| 型 | 級に応じた指定型 |
| 組手 | 約束組手、自由組手（級による） |
| 態度 | 礼法、返事、姿勢 |

※ 構成と合格基準は流派・道場によって異なります。所属道場の要項を必ず確認してください。

## 点が引かれやすいところ

### 1. 礼法

入退場、正面への礼、審査員への礼。ここは技術ではなく、やるかやらないかです。ここで崩れると、以降の印象に響きます。

### 2. 返事

名前を呼ばれたときの返事が小さいと、それだけで「稽古不足」と見られます。

### 3. 立ち方の高さ

緊張すると腰が浮きます。普段より一段低く構えるつもりでちょうど良くなります。

### 4. 引き手

技を出すことに意識が向いて、引き手が止まります。これは見る人にはすぐ分かります。

### 5. 目付け

型で向きを変えるとき、体より先に目線を送ります。床を見ていると全体の印象が落ちます。

## 審査の一週間前にやること

- **新しいことを足さない。** 直前に変えた癖は、緊張すると元に戻ります
- **型を通しで3本、毎日。** 回数より毎日続けることを優先します
- **自分の演武を動画に撮る。** 自分の感覚と外から見た姿は必ずずれています
- **道着と帯を確認する。** ほつれ、丈、結び方。当日に慌てないようにします

## 当日の流れ

1. 開始30分前には着替えを終える
2. 軽く体を温める。汗をかくほどはやらない
3. 型の順番を頭の中で一度だけ通す
4. 呼ばれたら大きく返事をして、走らず歩いて出る

## 落ちたときに見直すこと

審査で落ちるのは、多くの場合ひとつの項目です。何が足りなかったのかを指導者に必ず聞き、次の3か月はそこだけを重点的に稽古します。全部をやり直そうとすると、また同じところで止まります。
