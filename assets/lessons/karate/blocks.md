# 受けの基本

受けは「止める」技ではなく「そらす」技です。真正面から力でぶつかると、体格差がそのまま結果になります。相手の力の向きを変えることを意識します。

## 上段受け（じょうだんうけ）

顔面への攻撃を、額の上でそらします。

1. 受ける側の腕を、反対の肩の前に引き寄せる
2. 前腕を額の上へ振り上げ、小指側で受ける
3. 受けた腕は額から拳ひとつぶん離す
4. 反対の手は同時に腰へ引く（引き手）

**ポイント** 腕だけを上げると力が乗りません。腰の回転と同時に上げます。

## 外受け（そとうけ）

中段への攻撃を、外側へ払います。

1. 受ける腕を耳の横まで上げる
2. 肘を支点に、外から内へ振り下ろす
3. 拳は肩の高さ、肘は90度
4. 肘は体から拳ひとつぶん離す

## 内受け（うちうけ）

中段への攻撃を、内側から外へ払います。外受けと軌道が逆になります。

1. 受ける腕を反対側の腰へ下げる
2. 内から外へ、弧を描いて払う
3. 拳は肩の高さで止める

## 下段払い（げだんばらい）

下段への蹴りを払い落とします。基本稽古で最初に習う受けです。

1. 受ける腕を反対の肩の前に置く
2. 斜め下へ振り下ろす
3. 拳は太ももの前、拳ひとつぶん外側で止める
4. 腕は伸ばしきらず、肘に少し余裕を残す

## 手刀受け（しゅとううけ）

後屈立ちと組み合わせて使う受けです。手を開いたまま、小指側の刃で受けます。

- 指はそろえて伸ばし、親指は曲げて内側に寄せる
- 反対の手は鳩尾（みぞおち）の前に構える

## 受けが効かないときに見るところ

| 症状 | 見るところ |
| --- | --- |
| 押し負ける | 腰が回っていない。腕だけで受けている |
| 受けた後に体勢が崩れる | 立ち方が浅い |
| 次の技が遅れる | 引き手が止まっている |
| 手首が痛む | 拳と前腕が一直線になっていない |

> 受けと引き手は同時に終わります。片方が遅れると、どちらの力も半分になります。
