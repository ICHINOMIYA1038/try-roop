# 突きの基本技術

空手における「突き」は最も基本的な攻撃技です。正しいフォームを身につけましょう。

## 正拳突き（せいけんづき）

### 拳の握り方

正しい拳の作り方が怪我を防ぎます。

1. 指を順番に折り曲げる（小指から）
2. 親指を人差し指と中指の上に置く
3. 手首をまっすぐに保つ

### 突きの動作

**基本の流れ：**

```
構え → 引き手 → 突き出し → 引き戻し
```

- **引き手**: 反対の手を脇に引く
- **突き出し**: 腕をまっすぐ伸ばす
- **ひねり**: 腕を回転させながら突く

## 追い突き（おいづき）

前進しながら行う突きです。

| 動作 | ポイント |
|------|----------|
| 踏み込み | 後ろ足で蹴り出す |
| 体重移動 | 腰を入れる |
| 突き | 踏み込みと同時に |

## 逆突き（ぎゃくづき）

構えと反対の手で突く技です。威力が出やすい技です。

### コツ

- 腰の回転を使う
- 肩を入れ過ぎない
- 膝を曲げたまま維持

## 練習方法

### 空突き練習
1. 構えをとる
2. ゆっくり突き出す
3. 10回を3セット

### シャドー練習
鏡を見ながら、自分のフォームを確認しましょう。
