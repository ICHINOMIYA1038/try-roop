# 蹴りの基本技術

蹴り技は空手において強力な武器となります。バランスと柔軟性が重要です。

## 前蹴り（まえげり）

最も基本的な蹴り技です。

### 蹴り方

1. **膝を高く上げる** - 胸に引きつけるイメージ
2. **足首を曲げる** - 中足で蹴る準備
3. **真っ直ぐ蹴り出す** - 膝を伸ばしながら
4. **素早く引き戻す** - 蹴った足を戻す

### 当てる部分

- **中足（ちゅうそく）**: 足の指の付け根
- 当てる時は足首をしっかり曲げる

## 回し蹴り（まわしげり）

側面から弧を描いて蹴る技です。

### ポイント

| 部位 | 動き |
|------|------|
| 軸足 | つま先を外側に向ける |
| 腰 | 回転させる |
| 膝 | 横から振り上げる |
| 足 | 背足で当てる |

## 横蹴り（よこげり）

体の側面に向かって蹴る技です。

### 蹴込み（けこみ）
- 足刀（そくとう）で蹴る
- 体を横に倒さない
- 腰を入れて威力を出す

## 柔軟性の重要性

蹴り技には柔軟性が不可欠です。

### ストレッチ例

```
- 開脚ストレッチ：30秒×3セット
- 前屈ストレッチ：30秒×3セット
- 股関節回し：左右10回ずつ
```

> 毎日のストレッチで、蹴りの高さと威力が向上します。

## 安全に練習するために

- ウォームアップを必ず行う
- 無理に高く蹴らない
- 痛みがあれば休む
