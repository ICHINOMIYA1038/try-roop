# プロンプトエンジニアリング基礎

AIから最高の回答を引き出すためのプロンプト設計テクニックを学びます。

## プロンプトエンジニアリングとは

AIへの指示（プロンプト）を工夫することで、より良い回答を得る技術です。

### なぜ重要か

同じAIでも、プロンプト次第で：
- 回答の質が大きく変わる
- 作業効率が向上する
- より創造的な出力が得られる

## 基本テクニック

### 1. ロール設定

AIに特定の役割を与えます。

```
あなたはプロのコピーライターです。
10年の経験があり、数々の賞を受賞しています。
```

**効果**: 専門的で質の高い回答が得られやすい

### 2. 具体的な指示

曖昧さを排除し、具体的に伝えます。

| 悪い例 | 良い例 |
|--------|--------|
| 短くして | 100文字以内で |
| 分かりやすく | 小学生でも分かるように |
| きれいに | 見出しと箇条書きで整理して |

### 3. ステップバイステップ

複雑なタスクは段階に分けます。

```
以下のステップで作業してください：
1. まず文章を読んで要約する
2. 次に問題点を3つ挙げる
3. 最後に改善案を提示する
```

### 4. Few-shot プロンプト

例を示して、期待する出力を明確にします。

```
以下の形式で商品紹介を書いてください。

【例】
商品名: スマートウォッチX
特徴: 健康管理、通知確認、防水
おすすめポイント: 24時間健康データを記録

【依頼】
商品名: ワイヤレスイヤホンY
```

## 高度なテクニック

### チェーン・オブ・ソート

思考過程を明示的に要求します。

```
この問題を解いてください。
解答に至るまでの思考過程を
ステップバイステップで説明してください。
```

### 制約条件の設定

出力をコントロールします。

```
【制約条件】
・専門用語は使わない
・必ず具体例を含める
・ネガティブな表現は避ける
・300文字程度で
```

### 出力形式の指定

```
以下のJSON形式で出力してください：
{
  "title": "タイトル",
  "summary": "要約",
  "points": ["ポイント1", "ポイント2"]
}
```

## よくある失敗と対策

### 1. 情報が足りない

**失敗例**:
```
良いキャッチコピーを作って
```

**改善例**:
```
20代女性向けの新作コスメのキャッチコピーを作成してください。
商品の特徴は「24時間崩れない」「肌に優しい成分」です。
SNS広告用で、10文字以内でお願いします。
```

### 2. 回答が長すぎる

**対策**: 文字数や項目数を明示

```
3つのポイントに絞って、各50文字以内で説明してください。
```

### 3. 期待と違う出力

**対策**: 会話を重ねて調整

```
ありがとうございます。
もう少しカジュアルなトーンに変更してください。
また、具体的な数字を入れてください。
```

## プロンプトのテンプレート

### 汎用テンプレート

```
【役割】
あなたは[専門分野]の専門家です。

【背景】
[状況の説明]

【依頼】
[具体的なタスク]

【条件】
・[条件1]
・[条件2]

【出力形式】
[希望する形式]
```

## 実践演習

以下のプロンプトを改善してみましょう：

```
原文: 「アプリの説明を書いて」

改善後:
あなたはアプリマーケティングの専門家です。
以下のアプリのApp Store用説明文を書いてください。

アプリ名: FitLife
機能: 歩数計、カロリー管理、睡眠記録
ターゲット: 30-40代の健康意識の高い会社員

条件:
・500文字程度
・最初の1文で興味を引く
・3つの主要機能を箇条書きで
・最後に行動を促すCTAを含める
```

## まとめ

効果的なプロンプトのポイント：

1. **具体的に** - 曖昧さを排除
2. **構造化** - 役割・タスク・条件・形式
3. **例を示す** - 期待する出力を明確に
4. **反復改善** - 会話を重ねて精度を上げる
