# ChatGPT入門ガイド

AI時代に必須のスキル、ChatGPTの使い方を基礎から学びましょう。

## ChatGPTとは

ChatGPTは、OpenAIが開発した対話型AIです。

### できること

- 質問への回答
- 文章の作成・添削
- アイデアのブレインストーミング
- プログラミングのサポート
- 言語の翻訳
- 学習のサポート

### できないこと

- 最新情報の取得（学習データに期限あり）
- 正確性の保証（事実確認が必要）
- 専門的な判断（医療・法律など）

## 基本的な使い方

### アカウント作成

1. [chat.openai.com](https://chat.openai.com) にアクセス
2. 「Sign up」をクリック
3. メールアドレスで登録

### 会話の始め方

```
入力欄に質問や依頼を入力
→ Enterキーで送信
→ AIが回答を生成
```

## 効果的なプロンプトの書き方

### 基本構造

良いプロンプトには以下の要素があります：

| 要素 | 説明 | 例 |
|------|------|-----|
| 役割 | AIに演じてほしい役割 | 「プロの編集者として」|
| タスク | やってほしいこと | 「この文章を添削して」|
| 条件 | 制約や条件 | 「300文字以内で」|
| 出力形式 | 回答の形式 | 「箇条書きで」|

### 具体例

**悪い例**：
```
レポートを書いて
```

**良い例**：
```
私は大学生です。「地球温暖化の影響」について
2000文字程度のレポートを書いてください。
構成は「はじめに」「現状」「対策」「まとめ」で
お願いします。
```

## 活用シーン

### 1. 文章作成

```
【依頼】
以下の内容でビジネスメールを作成してください。
・会議の日程調整のお願い
・候補日は来週の火曜か水曜
・丁寧な文体で
```

### 2. 学習サポート

```
【依頼】
中学生に分かるように「光合成」を説明してください。
身近な例えを使って、300文字程度で。
```

### 3. アイデア出し

```
【依頼】
週末に家族で楽しめる低予算のアクティビティを
10個提案してください。
子供は5歳と8歳です。
```

## 注意点

> AIの回答は必ず自分で確認しましょう。

### 気をつけること

1. **個人情報を入力しない** - プライバシーに注意
2. **事実確認をする** - 誤情報の可能性
3. **著作権に配慮** - 生成物の利用ルール
4. **依存しすぎない** - 自分で考える力も大切

## まとめ

ChatGPTを使いこなすコツ：

1. **明確に伝える** - 曖昧さを減らす
2. **会話を重ねる** - 理想に近づける
3. **確認する** - 情報の正確性をチェック
