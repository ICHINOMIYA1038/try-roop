# try-roop の集客計画（2026-09-26）

公開から約4か月。評価0件、検索は自社名以外すべて圏外。
このままダウンロードを増やす施策を打っても、受け皿が壊れているので回収できない。
「直す → 見つかるようにする → 中身を足す → 広げる」の順に進める。

## 0. 前提の訂正（2026-09-26 実機確認）

シミュレータで動かしたところ、**ホームに何も表示されていなかった**。

```
ErrorView: type 'Timestamp' is not a subtype of type 'String'
```

本番の videos / courses / textLessons / badges は日時をすべて Firestore の
Timestamp で保存しているのに、アプリ側は文字列として読んでいた。
一覧の取得は成功していたが、変換で必ず例外になっていた。

つまり公開以来、**ダウンロードした人は全員エラー画面を見ていた**。
評価0件・レビュー0件の直接の原因はこれで、「コンテンツが少ない」以前の
問題だった。以下の分析はこれを直した前提で読むこと。

（修正済み。`lib/models/firestore_date.dart`）

実測すると、勝てる場所と勝てない場所がはっきり分かれる。

| 検索語 | 結果数 | 競合の最高評価数 | 判定 |

空手の学習アプリは事実上存在しない。市場は小さいが、1位を取れる。
筋トレは Nike や LEAN BODY がいる場所で、個人開発が入る余地はない。

**結論: アプリの看板を空手にする。** 筋トレ・健康・AI のレッスンは消さずに
「関連コンテンツ」として残すが、名前・サブタイトル・スクリーンショットからは外す。

## 3. 差し替える文言

### アプリ名（30字）

```
空手の稽古帳 - 型と基本を動画で学ぶ
```

「空手」を先頭に置き、「稽古」「型」「基本」「動画」を含める。
`try-roop` のブランド名は、サブタイトルと開発者名に残す。

### サブタイトル（30字）

```
昇級審査の対策から基本稽古まで
```

「昇級審査」は競合3件でどれも評価0件。ここは取りにいける。

### キーワード（100字・カンマ区切り、名前とサブタイトルの語は入れない）

```
空手道,karate,組手,突き,蹴り,受け,立ち方,平安,道場,帯,級,黒帯,子供,習い事,護身術,武道
```

### プロモーションテキスト（170字・審査なしで差し替え可）

```
新しく「立ち方を使い分ける」「受けの基本」「平安初段の流れ」「昇級審査でみられるところ」を追加しました。
審査前の確認にお使いください。
```

### 説明文の冒頭（検索結果に出る最初の3行が勝負）

```
空手の基本を、いつでも見返せる稽古帳。

ポイントまで。道場で教わったことを、家で確かめられます。
```

## 4. アイコンとスクリーンショット

**アイコン** いまは「try-roop campus」の文字と4つの小さな記号が入っていて、
ホーム画面の実寸では読めない。文字を捨てて、図ひとつにする。
道着の帯、あるいは正拳のシルエット。背景は単色、前景との明度差を大きく取る。

**スクリーンショット** 1枚目がコミュニティのダミー投稿（田中太郎・鈴木花子）になっている。
作り物に見えるうえ、アプリの価値が伝わらない。差し替える。

| 枚 | 内容 | 上に載せる文 |
| --- | --- | --- |
| 1 | レッスン一覧（空手のみ） | 空手の基本を、家で確かめる |
| 2 | 「受けの基本」の本文 | 効かない原因まで書いてある |
| 3 | 「平安初段の流れ」の動作表 | 型の順番と極めどころ |
| 4 | 「昇級審査でみられるところ」 | 審査で落ちるのは基本 |
| 5 | 学習ダッシュボード | 続けた日数が残る |

6.9インチ（iPhone 16 Pro Max）のサイズも必須。

**カテゴリ** 「ライフスタイル」から「教育」へ。第2カテゴリは「ヘルスケア・フィットネス」のまま。

## 5. 進める順番

| 段階 | やること | コンソール作業 |
| --- | --- | --- |
| 0 | **日時の不具合を直したビルドを提出**（これが出るまで誰もコンテンツを見られない） | ASC |
| 1 | 課金アイテムの登録、Firestore のルールとインデックス | ASC / Firebase 両方 |
| 2 | アプリ名・サブタイトル・キーワード・説明文・カテゴリの差し替え、アイコンとスクリーンショット | ASC |
| 3 | 空手のレッスンを増やす、空手の動画を1本でも入れる | 不要 |
| 4 | サイトの App Store リンク（対応済み）、共有・レビュー依頼（対応済み）、計測（対応済み） | デプロイのみ |

段階0を飛ばすと、他を全部やっても利用者にはエラー画面しか見えない。
段階1を飛ばして段階2をやると、見つかるようになった分だけ低評価が増える。

フォーム測定は 2026-09-26 に作ったが、学習アプリとしての性格と合わないため
外した（コミット履歴に残してある）。
