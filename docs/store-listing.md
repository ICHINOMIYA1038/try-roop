TikTok や Instagram で「Try Loop」を見た人が App Store で検索しても

## 入れる文言

### アプリ名（30字以内）

```
Try Loop｜15分LIVEレッスン
```

ブランド名を先頭に置く。SNS を見た人が最初に打つ言葉なので、
ここが一致していることが最優先。残りで「15分」「LIVE」「レッスン」を拾う。

### サブタイトル（30字以内）

```
筋トレ・ボクササイズ・韓国語
```

いま提供している3ジャンルをそのまま並べる。ジャンルが増えたら差し替える。

### キーワード（100字・カンマ区切り）

名前とサブタイトルに入れた語は書かない（重複は効かない）。

```
トライループ,tryloop,宅トレ,自宅,初心者,オンライン,講座,ライブ配信,運動不足,ダイエット,習慣,韓国語会話,ハングル,ボクシング,有酸素
```

カタカナの「トライループ」は必ず入れる。日本語話者は英字より
カタカナで検索することが多い。

### プロモーションテキスト（170字・審査なしで差し替え可）

LIVE の予定を書く枠として使う。毎週更新できる。

```
今週のLIVE
月 20:00 筋トレ / 火 20:00 韓国語 / 水 20:00 ボクササイズ
各15分。はじめての方は各講座の第1回を無料でご覧いただけます。
```

### 説明文の冒頭（検索結果に出るのは最初の3行）

```
「何か始めたいけど、何をすればいいかわからない」

Try Loop は、筋トレ・ボクササイズ・韓国語などの講座を、1回15分の
LIVEで体験できるサービスです。教室に通わなくても、自宅から参加できます。

■ 1回15分のLIVE
講師がその場で教えます。短いので、予定の合間に参加できます。

■ 見逃しても大丈夫
LIVEのあとはアーカイブで視聴できます。

■ 順番に進められる講座
「韓国語 第1回、第2回…」のように、どこまで進んだかが分かります。

■ まず試せます
各講座の第1回は無料です。合わなければ、別のジャンルを試してください。
```

### カテゴリ

「ライフスタイル」から「**ヘルスケア／フィットネス**」へ。
第2カテゴリは「教育」。いまは第1がライフスタイル、第2がヘルスケアで、
主役が入れ替わっている。

### スクリーンショット

1枚目に LIVE を置く。サービスの中心だから。
6.9インチ（iPhone 16 Pro Max）が未登録なので追加が必要。

| 枚 | 内容 | 上に載せる文 |
| --- | --- | --- |
| 1 | ホームの「本日のLIVE」 | 今日のLIVEは20:00から |
| 2 | LIVEの予定一覧 | 週に3回、1回15分 |
| 3 | 講座シリーズ（第1回・第2回…） | 順番に進められます |
| 4 | 受講済みと進捗 | どこまでやったかが残る |
| 5 | プラン | 各講座の第1回は無料 |

いまの1枚目はコミュニティのダミー投稿（田中太郎・鈴木花子）なので、
差し替えが必須。作り物に見えるうえ、サービスの中身が伝わらない。
